# only4u\n\nAn Android application for running unsensored GGUF language models using llama.cpp.\n\n## Features\n\n- Run GGUF models locally on Android devices\n- Integration with llama.cpp C++ backend\n- User-friendly chat interface\n- No internet connection required\n- Privacy-focused local inference\n- Support for multiple model architectures\n\n## Requirements\n\n- Android API level 21 or higher\n- Minimum 4GB RAM recommended\n- Sufficient storage for GGUF model files\n- Android NDK for building\n\n## Quick Start\n\n### 1. Clone the Repository\n```bash\ngit clone https://github.com/9555G/Only4u.git\ncd Only4u\n```\n\n### 2. Download llama.cpp\n```bash\ngit clone https://github.com/ggerganov/llama.cpp.git\ncp -r llama.cpp app/src/main/cpp/\n```\n\n### 3. Build the Project\n```bash\n./gradlew build\n```\n\n### 4. Install on Device\n```bash\n./gradlew installDebug\n```\n\n### 5. Add Your Model\n- Place your `.gguf` file in `/sdcard/Only4u/models/`\n- Open the app and select your model\n- Start chatting with the local model\n\n## Project Structure\n\n```\nonly4u/\n├── app/\n│   ├── src/\n│   │   ├── main/\n│   │   │   ├── java/com/only4u/\n│   │   │   │   ├── MainActivity.kt\n│   │   │   │   ├── LlamaService.kt\n│   │   │   │   └── MessageAdapter.kt\n│   │   │   ├── cpp/\n│   │   │   │   ├── llama_jni.cpp\n│   │   │   │   └── CMakeLists.txt\n│   │   │   ├── res/\n│   │   │   └── AndroidManifest.xml\n│   └── build.gradle.kts\n├── build.gradle.kts\n├── settings.gradle.kts\n└── LICENSE\n```\n\n## Building with llama.cpp\n\n1. Download llama.cpp:\n```bash\ngit clone https://github.com/ggerganov/llama.cpp.git\n```\n\n2. Place in your project:\n```bash\ncp -r llama.cpp app/src/main/cpp/\n```\n\n3. The CMakeLists.txt will automatically build llama.cpp with your app\n\n## API Usage\n\n### Loading a Model\n```kotlin\nval llamaService = LlamaService(context)\nval modelPath = \"/path/to/model.gguf\"\nif (llamaService.loadModel(\"model.gguf\")) {\n    // Model loaded successfully\n}\n```\n\n### Running Inference\n```kotlin\nval prompt = \"Hello, how are you?\"\nval result = llamaService.generate(prompt)\n```\n\n## Performance Tips\n\n- Use quantized models (Q4, Q5) for faster inference\n- Reduce max tokens for quicker responses\n- Test on physical devices (emulators may be slow)\n- Keep models on external storage\n\n## Troubleshooting\n\n### App crashes on startup\n- Check NDK version compatibility\n- Verify model file exists and is readable\n- Check logcat: `adb logcat | grep LlamaJNI`\n\n### Slow inference\n- Use quantized models\n- Reduce sequence length\n- Check device thermal state\n\n### Model not loading\n- Verify file permissions\n- Check model format is GGUF\n- Ensure sufficient free storage\n\n## License\n\nMIT License - See LICENSE file for details\n\n## Contributing\n\nContributions are welcome!
